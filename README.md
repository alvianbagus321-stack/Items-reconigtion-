📝 Main Application Features

Visual Search & Scanning (Two Main Modes)

Data Mode (Internal Inventory Search)

Use the camera or gallery photos to analyze items with AI, generate search keywords, and instantly match them against products stored in your local inventory database.

Online Mode (E-Commerce Price Search - NEW FEATURE)

Transforms Gemini AI into a smart shopping assistant. Identifies products from photos and searches for real-world pricing information from the internet and major e-commerce platforms.

Interactive Online Product Details (Online Mode)

Product Image & Price Range

Displays estimated product visuals along with dynamic market price ranges based on your selected currency.

Collaborative Product Description (Collapsible)

Features an interactive product description card that can be expanded or collapsed, keeping the interface clean and organized.

Popular E-Commerce Integration

Provides product information from major online marketplaces such as Tokopedia, Shopee, Lazada, Bukalapak, and Amazon, complete with brand-colored badges for easy recognition.

Direct Navigation ("Open Store")

Quick-access buttons that redirect users directly to product search pages on supported e-commerce websites.

Local Inventory Management (Room Database)

Add, edit, categorize, and delete inventory items.
Secure local data storage using Room Database.
Organize items into folders/groups for easier inventory management.
Flexible Customization & Settings

Gemini API Key Configuration

Configure your Gemini API key directly from the Settings page.

Currency Customization

Supports currency selection and automatic price conversion (for example, converting product prices to Indonesian Rupiah).

Visual Customization

Personalize the app appearance with settings such as:

Blur radius adjustment
Opacity control
Search bar color customization
Background color customization
Custom background image support
🛠️ Important Fixes & Improvements

Gemini Endpoint & Model Compatibility Fix

Issue

API key detection failures, 404 errors, or Bad Request responses occurred due to incompatible Gemini model endpoints or hidden spaces/characters within copied API keys.

Solution

Updated the REST API endpoint configuration to use stable Gemini models and implemented automatic string trimming to remove unwanted whitespace characters, preventing authentication failures caused by malformed API keys.

Camera Mode State Synchronization Fix

Issue

The selected mode before capturing an image was not always passed correctly to the Visual Search screen, causing inconsistent search results and state mismatches.

Solution

Updated the AppNavGraph navigation parameter system to properly carry the "initialMode" value from the Camera screen directly to the VisualSearchScreen, ensuring consistent state synchronization throughout the navigation flow.
